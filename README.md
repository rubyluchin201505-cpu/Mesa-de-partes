Prototipo de Mesa de Partes - I.E.I. N° 084 "Virgen María"
##RESUMEN DEL PROYECTO
Sistema desarrollado en Python para automatizar el registro, búsqueda, ordenamiento y almacenamiento local de trámites (inscripciones y traslados)
en la mesa de partes del Instituto Educativo Inicial N° 084 "Virgen María", reemplazando el llenado manual de fichas físicas mediante persistencia en archivos de texto 
plano.
